# Jogo de Reabilitação

## Organização do Projeto

### Releases semanais

Em cada release, você consegue acessar:
- `project.zip`: um arquivo compactado com todos os arquivos necessários para rodar o jogo.
- `main.pdf`: PDF do Short Paper

### Pasta `/docs`

Nesta pasta, temos:

* `/adr`: Principais decisões técnicas tomadas
* `/phase`: Atividades para a implementação do projeto, se baseando nas ADRs
* `/knowledge`: Resumos de artigos úteis para serem citados no projeto

### Pasta `/paper`

Contém os arquivos necessários para renderizar `main.pdf`

### Pastas do jogo: `/core`, `/lwjgl3`, `/assets` e as do gradle

Essas pastas contém a lógica principal, os anexos e os arquivos para gestão de dependências do gradle, sendo todas compactadas
em `project.zip`
