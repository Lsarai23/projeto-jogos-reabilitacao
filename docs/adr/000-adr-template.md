# [ADR-000] Título Curto e Imperativo da Decisão

* **Status:** [Proposto | Aceito | Depreciado | Substituído]
* **Data:** AAAA-MM-DD

## Contexto e Problema

Descreva o contexto que levou a essa necessidade.
* Qual é o problema que estamos tentando resolver?
* Quais são as restrições técnicas, de negócio ou de tempo?
* Quais opções foram consideradas?

## Decisão

Descreva a decisão tomada de forma clara.
* "Nós decidimos usar [Tecnologia/Padrão] para [Finalidade]..."
* Justifique a escolha baseando-se no contexto acima.

## Consequências

Descreva os resultados dessa decisão (o bom e o ruim). Toda decisão arquitetural tem trade-offs.
* **Positivo:** O que ganhamos? (Ex: Melhor performance, facilidade de contratação, consistência ACID).
* **Negativo:** O que perdemos ou o que se torna mais difícil? (Ex: Aumento da complexidade de deploy, curva de aprendizado, custo de licença).
* **Riscos:** Existe algum risco residual?

## Conformidade (Opcional)

Como vamos garantir que essa decisão está sendo seguida? (Ex: Testes automatizados, code reviews, linters).
